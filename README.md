# CareConnect
Node 20+. Run npm install and npm start. Open http://localhost:3000. For browser hosting import the ZIP into a Node-compatible service and set GEMINI_API_KEY in server secrets. Default model gemini-2.5-flash; override GEMINI_MODEL if needed (the configured model must support thinkingBudget). Free quota depends on provider eligibility. Dashboard readings and alerts are illustrative. Complaint classification uses keyword rules; tickets and manually advanced status are stored in browser localStorage only, with no external submission. Use fictional data only. Live API not tested. No API key included.
